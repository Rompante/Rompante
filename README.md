## Sobre mim

Olá! Sou o **Rompante**, uma pessoa apaixonada por tecnologia e desenvolvimento de software.

- Gosto de criar soluções práticas para problemas reais.
- Estou sempre a explorar novas linguagens, ferramentas e formas de melhorar o meu código.
- Valorizo projetos organizados, interfaces simples e código fácil de manter.
- O meu objetivo é continuar a evoluir através de projetos, colaboração e aprendizagem contínua.

> **Código não é apenas escrever instruções para um computador — é transformar uma ideia numa solução que pode ser usada por outras pessoas.**
